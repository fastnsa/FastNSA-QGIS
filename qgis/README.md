# FastNSA for QGIS: Installation and Guides

For the project introduction, screenshots, and downloads, visit the
[FastNSA-QGIS homepage](https://github.com/fastnsa/FastNSA-QGIS).

This page accompanies plugin version `0.1.1` and is included in the plugin ZIP.
Version 0.1.1 is being prepared for release.

## Installation

Follow [Installation](docs/installation.md) to choose a package, install it,
or upgrade an existing installation.

- **Self-contained Windows or Linux ZIP:** FastNSA is already included.
- **Source-only ZIP:** install `fastnsa==0.3.0` separately by following
  [Set Up FastNSA](docs/external-runtime.md). Open **FastNSA > Runtime setup**
  in QGIS to check the installation.

Save your work and restart QGIS after upgrading the plugin. For platform
support and required software, see [Software Requirements](DEPENDENCIES.md).
