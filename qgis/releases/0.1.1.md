# FastNSA for QGIS 0.1.1

This release has been withdrawn. Use 0.1.2 or a later release instead.

This update makes FastNSA easier to install and configure, and adds a
source-only installation option.

## New Since 0.1.0

- **Source-only package:** Use the plugin with FastNSA 0.3.0 installed
  separately in your QGIS Python environment or a dedicated user folder.
- **Runtime setup:** Check your installation and follow setup instructions
  directly from the FastNSA menu.
- **Automatic detection:** Find FastNSA in the recommended Windows and
  Linux installation folders.
- **First-time activation:** Enable the analysis tools after installing
  FastNSA without restarting QGIS, when no previous runtime is loaded.

## Improvements

- Clearer messages for missing packages, incompatible versions, and
  installations that require a restart.
- Improved Matplotlib cache handling for 3D views.
- Updated installation guides and Processing Toolbox descriptions.

The four analysis workflows remain unchanged. This release continues to
use FastNSA 0.3.0.

## Choose Your Download

| Package | FastNSA included? |
| --- | --- |
| `fastnsa_qgis-0.1.1-windows-amd64.zip` | Yes |
| `fastnsa_qgis-0.1.1-linux-x86_64.zip` | Yes |
| `fastnsa_qgis-0.1.1-source-only.zip` | No; install `fastnsa==0.3.0` separately |

Install the selected ZIP through QGIS's **Install from ZIP** option.
GitHub's automatically generated **Source code** archives are not
installable plugin packages.

Compatibility remains unchanged: QGIS 3.34-3.x with Qt5, Python 3.11+,
Windows AMD64 or Linux x86_64. Matplotlib is optional for 3D views.
