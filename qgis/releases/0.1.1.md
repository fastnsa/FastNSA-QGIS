# FastNSA for QGIS 0.1.1

This version is being prepared for release.

## Easier Setup

- Follow step-by-step installation help from **FastNSA > Runtime setup**.
- Find FastNSA automatically when installed in the recommended Windows or
  Linux user folder.
- Enable the analysis tools with **Check again** or **Save and enable** after
  a first installation, without an extra QGIS restart.
- Get clearer help when a package is missing, the wrong version is found, or
  QGIS needs to restart.

A new source-only ZIP lets you use FastNSA 0.3.0 installed separately.
Self-contained Windows and Linux ZIPs continue to include it.

Supports QGIS 3.34 through 3.x with Qt5 and Python 3.11 or newer on Linux
x86_64 and Windows AMD64. Matplotlib remains optional for interactive 3D views.
