# FastNSA for QGIS 0.1.0

FastNSA brings native-accelerated network spatial analysis to QGIS through an
interactive workspace and four Processing Toolbox algorithms.

## Included Workflows

- Nearest-edge matching with reusable edge IDs, offsets, distances, and network
  signatures; optional projected points and point-to-edge connector lines.
- Network kernel density visualization with ADA/LION and the Epanechnikov
  kernel, lixel line outputs, and configurable Turbo density styles.
- Network K-function with NS (exact), STARS (approximate), Monte Carlo
  envelopes, result tables, and interactive charts.
- Spatiotemporal network K-function with time-field/unit interpretation, 2D
  surfaces, envelopes, and optional interactive Matplotlib 3D views.

The plugin supports temporary outputs, GeoPackage/CSV export, background tasks,
progress details, cooperative cancellation, and reusable road-network caches.

## Installation and Compatibility

Download **one plugin ZIP** for your platform and install it through
**Plugins > Manage and Install Plugins > Install from ZIP**:

- `fastnsa_qgis-0.1.0-linux-x86_64.zip`
- `fastnsa_qgis-0.1.0-windows-amd64.zip`

Requires QGIS 3.34 through QGIS 3.x with Qt5, Python 3.11 or newer, NumPy, and
a compatible system C++ runtime. The ZIP bundles checksum-verified FastNSA
0.3.0, including the native library; no separate FastNSA installation is needed.
Matplotlib is optional. GeoPandas, Shapely, NetworkX, and OSMnx are not required.

macOS plugin packages and QGIS 4/Qt6 are not supported in this release. Native
cancellation is cooperative and may wait for the next safe checkpoint. Monte
Carlo analysis on large networks may take substantial time; start with small
threshold grids and a few simulations.

The platform ZIPs are distributed through GitHub Releases, not the official
QGIS plugin repository. GitHub's **Source code** ZIP is not installable.
Archive checksums, build metadata, validation reports, and a combined manifest
are attached. Automated runtime checks do not replace manual QGIS acceptance.
