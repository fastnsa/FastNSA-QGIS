# FastNSA QGIS v0.1.0

The first public release of **FastNSA QGIS**, a QGIS plugin for efficient road-network spatial analysis powered by a native C++ computation engine.

FastNSA integrates network-aware data preprocessing, spatial analytics, and result visualization into a unified QGIS workflow.

## Features

FastNSA provides four analysis workflows through its main window and the Processing Toolbox:

- **Nearest-Edge Matching:** Efficiently project spatial events onto road networks, with reusable edge IDs, offsets, and optional projection geometries.
- **Network Kernel Density Visualization (NKDV):** Generate network-constrained density maps using ADA and LION with the Epanechnikov kernel.
- **Network K-Function:** Analyze network spatial point patterns using exact (NS) and approximate (STARS) algorithms, with Monte Carlo simulation and interactive plots.
- **Spatiotemporal Network K-Function:** Explore spatial and temporal event interactions through 2D surfaces, statistical envelopes, and optional 3D visualization.

Additional capabilities include background processing, progress reporting, cooperative cancellation, GeoPackage/CSV export, and reusable road-network caches.

Interactive charts and surface viewers are available from the plugin's main window; Processing Toolbox algorithms produce layers and tables without opening these viewers.

## Installation

Download the plugin ZIP corresponding to your operating system from the release assets:

| Platform | Package |
|---|---|
| Linux (x86-64) | `fastnsa_qgis-0.1.0-linux-x86_64.zip` |
| Windows (x64) | `fastnsa_qgis-0.1.0-windows-amd64.zip` |

In QGIS, navigate to **Plugins → Manage and Install Plugins → Install from ZIP**, select the downloaded package, and install the plugin.

**FastNSA Core v0.3.0 is bundled with the plugin.** No separate installation of the FastNSA Python package or native library is required.

**Important:** Use the platform-specific plugin ZIP, not GitHub's automatically generated "Source code" archives.

## Requirements and Compatibility

- **QGIS:** 3.34 or newer within the QGIS 3.x / Qt5 series
- **Python:** 3.11 or newer
- **Platforms:** Linux x86-64 and Windows x64
- **Dependencies:** NumPy and a compatible C++ runtime
- **Optional:** Matplotlib for interactive spatiotemporal 3D surfaces; other views remain available without it

GeoPandas, Shapely, NetworkX, and OSMnx are not required.

macOS and QGIS 4 / Qt6 are not supported in this release.

## Notes

Monte Carlo simulations on large road networks may take longer to complete. We recommend starting with a small number of simulations and distance thresholds.

Cancellation is cooperative and may wait until the native computation reaches its next safe checkpoint.
