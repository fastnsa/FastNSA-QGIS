# FastNSA for QGIS 0.1.2

This release replaces the withdrawn 0.1.1 release. It provides the same four
analysis workflows with FastNSA 0.3.0 and updated installation packages.

## New Since 0.1.0

- **Source-only installation:** Use FastNSA installed separately in QGIS's
  Python environment or a dedicated user folder.
- **Guided setup:** Check your installation and follow instructions from
  **FastNSA > Runtime setup**.
- **Automatic detection:** Find FastNSA in the recommended Windows and Linux
  installation folders.
- **First-time activation:** Enable the tools after installing FastNSA
  without restarting QGIS, when no previous runtime is loaded.
- Clearer installation messages, updated guides, and improved Matplotlib
  cache handling for 3D views.

## Downloads

| Package | FastNSA included? |
| --- | --- |
| `fastnsa_qgis-0.1.2-windows-amd64.zip` | Yes |
| `fastnsa_qgis-0.1.2-linux-x86_64.zip` | Yes |
| `fastnsa_qgis-0.1.2-source-only.zip` | No; install `fastnsa==0.3.0` separately |

Install the selected ZIP using QGIS's **Install from ZIP** option. GitHub's
automatic **Source code** archives are not installable plugin packages.

Supports QGIS 3.34-3.x with Qt5 and Python 3.11+ on Windows AMD64 or Linux
x86_64. Matplotlib is optional for 3D views.
