about=Study where events concentrate along roads and how their spatial and temporal patterns vary. Match event locations to the network, create density maps with ADA or LION, and explore network K-function results with NS (exact), STARS (approximate), or spatiotemporal methods. Use the FastNSA window for interactive maps and charts, or the Processing Toolbox for repeatable workflows. Supports Linux x86_64 and Windows AMD64 with QGIS 3.34 through 3.x, Qt5, and Python 3.11 or newer. Requires NumPy >= 1.23.5 and a compatible system C++ runtime. The source-only plugin needs the external Python package fastnsa==0.3.0 installed separately; the self-contained GitHub packages already include it. Open FastNSA > Runtime setup for step-by-step installation help. Packages are not installed automatically. Matplotlib is optional for interactive 3D views; other analyses work without it. macOS and QGIS 4/Qt6 are not supported in this release.
changelog=0.1.1: Easier first-time setup with installation help and automatic detection of FastNSA in the recommended folder. First-time setup can enable the tools without restarting QGIS. Adds a source-only installation option alongside the self-contained Windows and Linux packages.
