about=Release candidate with separate Linux x86_64 and Windows AMD64 packages for nearest-edge preprocessing, network kernel density visualization (ADA/LION), network K-function (NS exact/STARS approximate), and spatiotemporal network K-function. Targets QGIS 3.34 through 3.x with Qt5 and Python 3.11 or newer. Includes reusable point-to-network mappings, temporary result layers and tables, CSV export, non-modal background execution, and cooperative cancellation. Bundles the lightweight FastNSA runtime and platform-specific native library. Requires NumPy and a compatible system C++ runtime; Matplotlib is optional for interactive ST 3D surfaces. macOS plugin packages and QGIS 4/Qt6 are not yet supported. Install the package matching your operating system and architecture.
