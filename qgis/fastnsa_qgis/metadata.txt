about=Separate Linux x86_64 and Windows AMD64 packages for nearest-edge preprocessing, network kernel density visualization (ADA/LION), network K-function (NS exact/STARS approximate), and spatiotemporal network K-function. Targets QGIS 3.34 through 3.x with Qt5 and Python 3.11 or newer. Includes reusable point-to-network mappings, temporary result layers and tables, CSV export, non-modal background execution, and cooperative cancellation. Bundles FastNSA 0.3.0 and its platform-specific native library. Requires NumPy and a compatible system C++ runtime; Matplotlib is optional for interactive ST 3D surfaces. macOS plugin packages and QGIS 4/Qt6 are not yet supported. Install the package matching your operating system and architecture.
changelog=0.1.0: First stable release with nearest-edge matching, ADA/LION density layers, NS/STARS network K-function and spatiotemporal K-function; reusable mappings, temporary and exported results, background execution and cancellation, interactive charts and optional Matplotlib 3D surfaces. Bundles checksum-verified FastNSA 0.3.0 for Linux x86_64 and Windows AMD64.
