# Algorithm References

FastNSA adapts the algorithms below for its native backend and QGIS workflow.
The papers define the algorithmic ideas; plugin validation, output schemas,
normalization, cancellation, and persistence behavior are documented by this
release and may differ from research artifact interfaces.

## Nearest-Edge Matching

Hongwei Ye, Tsz Nam Chan, Dingming Wu, Leong Hou U, and Ruisheng Wang. 2026.
**An Efficient and Accurate Grid Compression Solution for Point-to-Line Nearest
Neighbor Search.** In *Proceedings of KDD 2026*, 6152-6163.
[DOI: 10.1145/3770855.3817711](https://doi.org/10.1145/3770855.3817711).

Artifact: [fastnsa/grid-comp-plnns](https://github.com/fastnsa/grid-comp-plnns).

## Reporting Results

Cite the paper corresponding to the selected method and also record the
FastNSA plugin version, QGIS version, method, parameters, random/simulation
settings, input CRS, and access date. Algorithm-paper citations do not replace
a future version-specific FastNSA software citation.
